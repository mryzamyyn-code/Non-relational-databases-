# Каталог электроники на MongoDB

## 1. Описание проекта

Проект представляет собой каталог электроники с быстрым поиском и фильтрацией товаров. Для хранения данных используется MongoDB Atlas, для взаимодействия с базой — Python и библиотека PyMongo.

## 2. Технологии

- Python
- MongoDB Atlas
- PyMongo
- python-dotenv
- pytest

## 3. Структура проекта

- `src/` — основной код приложения
- `scripts/seed_data.py` — заполнение базы тестовыми товарами
- `scripts/demo_queries.py` — демонстрационные запросы
- `tests/test_catalog.py` — автоматические тесты
- `docs/` — документация проекта
- `.env` — настройки подключения к базе данных

## 4. Настройка и запуск

1. Установить Python.
2. Создать виртуальное окружение.
3. Установить зависимости командой `python -m pip install -r requirements.txt`.
4. Создать файл `.env` и указать переменную `MONGODB_URI` со строкой подключения к MongoDB Atlas.
5. Заполнить базу командой `python scripts/seed_data.py`.
6. Выполнить демонстрационные запросы командой `python scripts/demo_queries.py`.
7. Запустить тесты командой `python -m pytest -v`.

## 5. Данные

В коллекции `products` хранятся название товара, категория, бренд, цена и остаток на складе. Подготовлено 30 синтетических записей для демонстрации.

## 6. Реализованные запросы

- Вывод списка товаров
- Поиск по категории
- Поиск по бренду
- Фильтрация по цене
- Сортировка по цене
- Поиск товаров с достаточным остатком
- Фильтрация по бренду и цене
- Агрегация количества товаров и средней цены по категориям

## 7. Индексы

Создаются индексы по сочетаниям `category + price` и `brand + price`, а также текстовый индекс по полю `name`.

## 8. Тестирование

Последний подтверждённый запуск: `3 passed in 10.69s`.

Проверены подключение к MongoDB, наличие 30 демонстрационных товаров и обязательные поля записи товара.

## 9. Безопасность

Файл `.env` содержит секретные данные подключения и не должен публиковаться в GitHub. Для публикации проекта следует использовать `.env.example` без реальных паролей.
